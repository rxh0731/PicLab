# 图片实验室

图片实验室是独立的整幅文献图片预处理工具，面向碑文拓片、手稿扫描件及其他文字图片。它通过背景清理、噪点抑制、文字区域复核和人工笔刷辅助，生成便于后续 Photoshop 精修的结果。

## 启动

首次使用请双击 `安装图片实验室依赖.bat`。依赖安装完成后，双击 `启动图片实验室.bat`，或在项目目录执行：

```text
.venv\Scripts\python.exe main.py
```

项目不内置样本图片；使用“打开图片”载入本地图片，使用“保存项目”保存 `.fontlab` 项目文件。

## 运行依赖

依赖版本记录在 `requirements.txt`，虚拟环境位于项目目录的 `.venv`，不会依赖原字库编辑器目录。当前使用 Python 3.12 和 PySide6 6.11.2。支持 TIFF、PNG、JPEG、BMP、WebP 等常用图片格式，并支持 PSD/PSB 导出。

## 目录

- `core/`：背景清理、笔画重建、区域检测算法。
- `data/`：图片实验室项目 SQLite 存储和日志管理。
- `services/`：预览、高清区域处理和完整尺寸导出服务。
- `ui/`：PySide6 页面、画布、主题和后台任务。
- `tests/`：图片实验室专项测试。
- `assets/piclab_icon.png`：应用图标。
- `图片实验室_算法研究记录.md`：真实样本研究和算法决策记录。

## 开发约定

所有用户可见文字、注释、日志和文档使用简体中文。图片始终保留在原路径，项目文件只保存源图信息、处理参数、区域和人工笔刷动作。新功能应先补充测试，再修改算法或界面。
